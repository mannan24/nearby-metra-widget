Nearby Metra

An iPhone widget for the nearest Metra Electric station, trains to and from Millennium Station, and estimated walking time.

Setup status: Automatic timetable hosting is included. Live predictions and walking routes require provider API keys entered once in Scriptable. Without them, the widget shows scheduled trains and “Walking key needed”.

Download Nearby Metra.js

Install on her iPhone

  1. Install Scriptable and open it once.
  2. Download the script above. In Files, move it to iCloud Drive → Scriptable. Keep the .js extension. If the folder is unavailable, open the file as text, copy it into a new Scriptable script, and name it “Nearby Metra”.
  3. Run Nearby Metra. Choose Configure API keys and enter the two keys below. Then allow location access. In iPhone Settings → Privacy & Security → Location Services → Scriptable, enable precise location and widget access if offered.
  4. Touch and hold the Home Screen → Edit → Add Widget → Scriptable. Add a medium widget. Touch and hold it → Edit Widget → Script → Nearby Metra. Leave Parameter empty.

One-time service setup

  • Metra developer access: request a GTFS realtime API key. The key request form is linked from their developers page. Approval may not be instant.
  • HeiGIT / openrouteservice account: create a free Standard API key for walking directions. Enter your own key on the phone; do not post it in the repository or chat.

No Cloudflare account or Apple Developer membership is needed. The repository and timetable use free GitHub Pages hosting. Provider free quotas and availability apply.

What the two times mean

  • To Millennium: the next train departing the nearby station toward Millennium.
  • From Millennium: the next train arriving at the nearby station that originated at Millennium. At Millennium itself, this is the next outbound departure.
  • Walk: estimated walking route duration to the station coordinates, not platform access time. Tap the walking row for Apple Maps directions.
  • Leave: a planning estimate for the next train you can reach, allowing the estimated walk plus three minutes. When the first train is too close, the line identifies the later train.

Automatic updates and their limits

The public timetable is rebuilt twice daily. The widget automatically requests location and data when iOS runs it; it requests another refresh after five minutes. iOS controls the actual frequency, so it may refresh later. Check the “As of” time before relying on it. This is not a continuously updating departure board.

Each train says “Live prediction” only when a fresh stop-specific prediction is available. Otherwise it says “Scheduled”. Live feed data more than five minutes old is rejected. The timetable is rejected if the hosting job has not refreshed it for 48 hours. Permissions, network outages, provider quota changes, or disabled GitHub workflows can interrupt updates.

Nearest means closest by geographic distance among Metra Electric stations, the line serving Millennium. It does not compare walking routes to every station, cover other Metra lines, or include South Shore trains. The widget works within 10 km of a Metra Electric station. A recent cached location may be used for up to five minutes and is labelled.

Privacy and credits

Keys are stored in Scriptable’s Keychain. Location is held in the phone’s cache and sent to HeiGIT only to calculate walking routes. GitHub receives station timetable requests but no GPS coordinates; GitHub may log IP addresses. Metra receives the live-data key.
